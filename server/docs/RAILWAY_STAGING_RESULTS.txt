3. ВХОД И ИЗОЛЯЦИЯ — ПРОШЛИ
Автоматическая анонимная сессия без API_TOKEN.
Secure, HttpOnly, SameSite=Lax, host-only cookie через реальный Railway HTTPS.
GET health/session сам по себе не создает постоянную сессию.
CSRF без nonce и запрос с чужим Origin отклоняются.
Разные посетители получают разные principals и видят только свои списки.
Чужие чтение, изменение, cart, workspace, AI, research, confirmation и
home/car insurance routes возвращают 404 до обращения к провайдерам.
Legacy shared bearer token не дает обхода публичной авторизации.
owner/admin роль не принимается из произвольного тела запроса.
Искусственный legacy-проект доступен только отдельному администратору.
Вход и выход администратора проверены через API и Settings UI.
Ключ администратора не сохраняется в localStorage.
Обновление сессии меняет credential, сохраняет principal/квоту/проекты;
старый credential сразу перестает работать. Logout отзывает доступ.
Новая сессия не может присвоить старые проекты.
